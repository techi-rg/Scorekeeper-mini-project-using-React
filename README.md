## 🔹 DETAILED README (Full Explanation)

### 📌 About the Project
The **Score Keeper App** is built to understand how React works internally when used directly through CDN links.  
Instead of using `useState`, the app manually re-renders components using `ReactDOM.createRoot()` to clearly demonstrate React’s rendering behavior.

---

### ✨ Features

- Buttons to add runs (0–6)
- Wicket tracking
- Live score display
- Ball-wise commentary input
- Match history displayed in order
- Responsive & clean UI
- Background image for better UX

---

### 🛠 Tech Stack

- **HTML** – Structure
- **CSS** – Styling & layout
- **JavaScript** – Logic
- **React (CDN)** – UI rendering
- **ReactDOM** – DOM updates
- **Babel** – JSX support in browser
